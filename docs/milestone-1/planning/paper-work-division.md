## Required Repository / Submission Items Tracked Outside the Main Paper Sections

These items must still be completed even if they are not expanded into large standalone report sections:

- Working end-to-end core MVP
- Authentication
- Complete source code
- Clear setup and run instructions
- Required software and versions
- Dependency installation instructions
- Environment-variable documentation
- Safe example environment file (for example, `.env.example`)
- Database migration instructions
- Seed/sample data or demonstration accounts when applicable
- Short TA verification guide
- Working MVP demonstration
- GitHub repository link
- Git tag: `milestone-1`

## Deferred / Non-M1 Features

The following features remain outside the Milestone 1 core MVP unless the team later decides otherwise and documents the scope change:

- Task Attention Level
- Advanced search and filtering
- Workload analytics or recommendations
- Calendar or timeline view
- Reminder notifications
- External calendar synchronization
- AI-assisted task decomposition
- Automatic syllabus parsing
- Machine-learning prediction
- Social/collaborative features
- Native mobile applications

## Contribution Tracking

The responsibility assignments above are the current planning baseline only.

- Work may cross planned responsibility boundaries when integration, review, schedule, or project needs require it.
- Actual contribution should be recorded through GitHub Issues, individual commits, Pull Requests, reviews, and completed artifacts.
- If the plan changes, document the change when it occurs instead of rewriting the earlier history to make the original plan appear different.
